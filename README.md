# WTV Driver Market Website

## Lokal öffnen
Einfach `index.html` doppelklicken.

## Kostenlos online stellen
Die Dateien können z. B. in ein GitHub-Repository hochgeladen und mit GitHub Pages veröffentlicht werden.

Ordnerstruktur:
- index.html
- assets/wtv-driver-market-logo.png
- downloads/WTV_Driver_Market_V3.zip
- downloads/WTV_Driver_Market_V2.1.zip

Die Download-Buttons funktionieren relativ zur Website, solange die ZIP-Dateien im `downloads`-Ordner liegen.


## Aktueller Versionsstand
- V2.1 = aktuelle stabile Hauptversion
- V3 = noch in Entwicklung / nicht als fertige Hauptversion veröffentlicht
