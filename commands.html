COMMAND CENTER

Alle Commands.
Einfach erklärt.

Filtere nach Berechtigung und klicke einen Command an, um Erklärung und Beispiel zu sehen. Die Seite enthält stabile Funktionen, V3.4-Funktionen und die neuen V2.2-TEST-Funktionen.

Tipp: Ein Command kann in verschiedenen Versionen unterschiedliche Berechtigungen haben.

/drivermarket V2.2 • V3.4

Fahrermarkt nach Teams.

Öffentlich

Zeigt die gespeicherten Fahrer teamweise mit Marktwert und Vertragsdaten.

Beispiel
/drivermarket
/alldrivers V2.2 • V3.4

Kompakte Fahrerliste.

Öffentlich

Zeigt alle gespeicherten Fahrer in einer kompakten Übersicht.

Beispiel
/alldrivers
/driverinfo V2.2 • V3.4

Komplettes Fahrerprofil.

Öffentlich

Zeigt Team, Marktwert, Vertrag, Gehalt, Boni und Klauseln eines Fahrers.

Beispiel
/driverinfo fahrer:Mario
/help V2.2 • V3.4

Command-Übersicht direkt in Discord.

Öffentlich

Zeigt die verfügbaren Befehle und deren Berechtigungsgruppen.

Beispiel
/help
/version V2.2 TEST

Zeigt die laufende Bot-Version.

Öffentlich

Hilfreich, um sofort zu erkennen, ob gerade der Testbot oder die stabile Version läuft.

Beispiel
/version

Öffentlich

Zeigt Teamwechsel, Marktwertänderungen, Vertragsänderungen und weitere protokollierte Aktivitäten.

Beispiel
/seasonstatus saison:6

/adddriver V2.2 Admin • V3.4 Transferleitung • V2.2 TEST Admin

Fahrer hinzufügen.

Transferleitung • Admin

In V2.2 TEST wird zuerst ein Fahrer gesucht. Danach öffnet sich ein Formular für Marktwert, Laufzeit, Gehalt, Klausel und Boni.

Beispiel
/adddriver fahrer:Mario
/editdriver V2.2 Admin • V3.4 Transferleitung • V2.2 TEST Admin

Fahrerdaten bearbeiten.

Transferleitung • Admin

Die Testversion zeigt nach der Fahrerauswahl ein Dropdown. Dort wird ausgewählt, welcher einzelne Wert geändert werden soll.

Beispiel
/editdriver fahrer:Mario
/transferdriver V2.2 Admin • V3.4 Transferleitung • V2.2 TEST Admin

Fahrer transferieren.

Transferleitung • Admin

Ändert Team und Discord-Teamrolle. Die Testversion öffnet zusätzlich ein Formular für optionale Vertragsänderungen.

Beispiel
/transferdriver fahrer:Mario neues_team:Ferrari
/removedriver V2.2 Admin • V3.4 Transferleitung • V2.2 TEST Admin

Fahrer entfernen.

Transferleitung • Admin

Entfernt einen Fahrer aus dem Fahrermarkt. In der Testversion gibt es davor eine Sicherheitsabfrage.

Beispiel
/removedriver fahrer:Mario
/renewcontract V3.4

Vertrag verlängern.

Transferleitung

Verlängert bzw. ersetzt die Vertragslaufzeit eines Fahrers.

Beispiel
/renewcontract fahrer:Mario
/setmarketvalue V3.4

Marktwert setzen.

Transferleitung

Ändert gezielt den Marktwert eines Fahrers.

Beispiel
/setmarketvalue fahrer:Mario
/botstatus V3.4

Technischer Botstatus.

Transferleitung

Prüft Bot, Speicher und bekannte Rollen sowie die Transferleitungsrolle.

Beispiel
/botstatus
/saison V2.2 • V3.4

Saisonnummer direkt setzen.

Admin

Setzt nur die Saisonnummer. Verträge werden dadurch nicht automatisch verändert.

Beispiel
/saison nummer:6
/datastatus V2.2 TEST

Daten- und Railway-Status.

Admin

Zeigt Fahrer, Transfers, Audit-Einträge, Speicherpfad und warnt, wenn kein Railway Volume erkannt wird.

Beispiel
/datastatus

/auditlog anzahl:10

Beispiel
/newseason
